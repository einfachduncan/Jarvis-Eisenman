# PHASE 1 — Grundprojekt

## Regeln
- Analysiere zuerst den bestehenden Code.
- Erhalte die Architektur.
- Implementiere ausschließlich diese Phase.
- Teste den gesamten Code.
- Behebe alle Fehler.
- Aktualisiere README.
- Aktualisiere requirements.txt.
- Erstelle bei Bedarf neue Dateien.
- Gehe NICHT zur nächsten Phase.

---

## Ziel

Ein funktionierender Terminal-Chat mit Gemini.

## Aufgaben

- Projektstruktur prüfen
- Fehlende Ordner anlegen
- `.env` anlegen
- `.gitignore` anlegen
- `README.md` anlegen
- `requirements.txt` anlegen
- Gemini verbinden
- Funktion `ask(prompt)` implementieren
- `main.py` erstellen
- Fehlerbehandlung implementieren
- Konfiguration einrichten

## Noch NICHT implementieren

- Sprache
- Kamera
- GUI
- Memory
- PC-Steuerung
